# Account Web Application - The Ultimate Student Application
**One place to run a student life.** Grades, deadlines, classes and money normally live in four apps that know nothing about each other, which leaves the student as the integration layer, manually entering the same assignment as a calendar event, a to-do and a row in a grade calculator, and still not knowing what next week actually costs. 
Account is built on the premise that these are not several subjects but one individual, and that the answers worth having only appear where they meet: a dated assignment is a task *and* a calendar block, a course carries a cost and a target, a term has a budget that knows when it begins and ends. Track earnings and budget usage like never before.

The aim is a tool good enough to live in every day, not one to demonstrate — built for real use first, and meant to be worked on and relied on for years rather than finished.
